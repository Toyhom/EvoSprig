# Interface fonts

Manrope (body), Plus Jakarta Sans (headings), IBM Plex Mono (code) and a Noto Sans SC subset (Chinese interface text), distributed under the SIL Open Font License 1.1. The adjacent license files contain the copyright notices and redistribution terms.

Sources: [Manrope](https://github.com/sharanda/manrope), [Plus Jakarta Sans](https://github.com/tokotype/PlusJakartaSans), [IBM Plex](https://github.com/IBM/plex), [Noto CJK](https://github.com/notofonts/noto-cjk). Webfonts contain subsets of the original glyphs. System CJK fonts handle characters outside the interface subset.
