Adapt the story into one complete 4–8 panel comic chapter. Choose a visual style that fits the story and keep it fixed. Establish each character's age, silhouette, hair, clothing and distinctive prop in a short description with a stable ID. Prefer one or two characters for a short story.

Every panel needs a concrete visible action, setting and camera framing. Use only character IDs declared in the cast. Tell a small complete story: situation, change, consequence, closing beat. Captions and dialogue are typeset by the layout tool, so the image descriptions request no letters, watermarks or speech text. For Chinese, each caption and dialogue must stay below 35 characters. For other languages keep each below 55 characters. Include the speaker's name before dialogue; omit dialogue if no one speaks.
