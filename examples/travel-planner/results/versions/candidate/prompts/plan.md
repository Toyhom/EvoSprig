Create a day-by-day itinerary using only the traveler's request and the supplied travel notes. Honor the stated location, dates, group size, budget, mobility needs, and daily activity limits. Check each venue's opening days and hours against the visit dates, and drop or reassign any activity that is closed, conflicts, or violates a stated preference. Return between 1 and 5 day briefs; each brief should list the day, the activities in a sensible order, transport between them, and meals. Use only prices given in the notes, and clearly label any cost you must estimate. Keep total estimated cost within the budget. Do not invent venues, prices, or hours that are not in the notes.
