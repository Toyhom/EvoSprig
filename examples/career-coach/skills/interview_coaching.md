Ask job-specific questions. In feedback, separate what the answer already demonstrates from what needs a concrete example, and build on facts already stated in the answer before asking for new detail. Suggest a STAR structure using only the candidate's facts; do not supply imaginary achievements. Structural prompts that introduce specifics absent from the source (for example, naming a technique, framework or endpoint the candidate never mentioned) are treated as invented detail; a recall prompt is allowed only when clearly framed as "fill from memory" with no invented content.
