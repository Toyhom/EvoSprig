# Learn EvoSprig

[English](README.md) · [简体中文](../zh-CN/tutorials/README.md)

Build something you can run, then learn the next feature by changing it. These tutorials take you through a complete application. Keep the [reference documentation](../README.md) open when you need a field, API or deployment option.

| Lesson | You will finish with | Time to follow |
| --- | --- | --- |
| [Your first agent](first-agent.md) | A saved workflow you can run and edit in Studio | 5 minutes |
| [Comic Studio on the canvas](comic-studio.md) | A customized story → panels → review → page application | 10 minutes |
| [Move from canvas to Python](canvas-to-python.md) | An exported application and a small SDK change | 10 minutes |
| [Improve an agent on your tasks](improve-an-agent.md) | A task suite, a candidate and a version comparison | 15 minutes |

Image generation and model calls run on your configured services. The lesson times describe the walkthrough.

New to agents? Start with the first lesson. Already have an application? Jump to the comic tutorial or [connect your models](../model-connections.md). To integrate a new algorithm, use the [contributor guide](../extend-framework.md).
