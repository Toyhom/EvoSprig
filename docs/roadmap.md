# Development roadmap

当前先完成开源 Alpha：构建、运行、调试、记忆与检索、评测和进化、版本选择、独立导出与自托管。每项能力依据自动测试和真实样例更新支持矩阵。

Alpha 后的部署专项针对平台后端：API/事件服务与任务 worker 分离，持久队列与租约、连接池、背压、交互/评测任务公平调度、PostgreSQL 与对象存储、多 worker 和多节点部署。

性能优化从固定硬件上的混合负载基准开始，记录吞吐、尾部延迟、排队时间、CPU/内存/GPU/网络/I/O 利用率及成本。使用可复现的前后对比决定配置和架构调整。模型推理服务与平台控制面分别部署和测量。

Studio 视觉与交互重构（DEV-018，首轮已实现）：以白色、浅灰和深灰文字建立中性界面，品牌色用于重点状态；梳理项目导航、画布节点、参数编辑、运行反馈和数据页面。以现代开发工具的实际界面作为参考，验证桌面/窄屏、长名称、大量项目与键盘交互。此项与平台性能路线分别推进。

首轮实现说明与参考来源见 [Studio interface](studio-design.md)。后续继续深化复杂工程的信息架构、加载/错误反馈和可访问性。
